# UltraEdit Navigation Clone

This project is a simple HTML and CSS clone of the **UltraEdit website navigation bar**.

## 🧠 Features
- Responsive layout using Flexbox  
- Clean and minimal design  
- Includes SVG dropdown icons  
- Uses UltraEdit logo and assets  

## 🧰 Tech Used
- HTML5  
- CSS3
